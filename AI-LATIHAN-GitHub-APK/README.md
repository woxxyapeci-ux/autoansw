# AI-LATIHAN Android + GitHub Actions

Ini adalah proyek Android yang membungkus UI AI-LATIHAN v12 sebagai aplikasi Android. UI disimpan lokal di APK; endpoint AI tetap harus diarahkan ke backend Vercel agar API key Gemini tidak dimasukkan ke APK.

## Build otomatis
1. Buat repository GitHub baru.
2. Upload seluruh isi folder ini ke repository.
3. Buka tab **Actions**.
4. Workflow **Build APK** akan berjalan otomatis.
5. Setelah selesai, buka run tersebut → **Artifacts** → download `AI-LATIHAN-debug-apk`.

Tidak perlu Android Studio di PC.
