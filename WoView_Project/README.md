# WoView App

Aplikasi Android berbasis Web (WebView) dengan tampilan modern dan responsif.

## Fitur
- UI/UX yang modern menggunakan HTML, CSS, JS murni
- Galeri foto random (terhubung dengan internet via Unsplash API)
- GitHub Actions CI/CD siap pakai untuk *build* APK secara otomatis menjadi `woview.apk`

## Cara Download APK dari GitHub
1. Upload/Push *source code* ini ke *repository* GitHub Anda.
2. Buka tab **Actions** di repo Anda.
3. Tunggu proses **Build Android APK** selesai.
4. Download artifact **woview-apk** di bagian bawah *Summary* build tersebut. Di dalamnya terdapat file `woview.apk`.
